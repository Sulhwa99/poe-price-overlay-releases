PoE 시세 오버레이 (카카오 서버)

패스 오브 엑자일 카카오 서버용 무료 시세 확인 도구입니다. 게임에서 아이템에 마우스를 올리고 Ctrl+D를 누르면, 게임 화면 위에 시세 창이 뜹니다.

⬇ 최신 버전 받기

PoEPriceOverlay-Setup-x.y.z.exe 를 받아 실행하면 됩니다.

게임 파일·메모리를 읽거나 바꾸지 않고, 마우스를 대신 움직이지 않으며, 화면을 캡처하지 않습니다. 키 한 번에 클립보드 복사 한 번, 그리고 공식 거래소 웹 API만 씁니다.
그래도 계정 제재 여부는 운영사가 정합니다. 사용에 따른 책임은 사용자 본인에게 있습니다.
할 수 있는 것
단축키	기능
Ctrl+D	시세 창 — 고유·화폐·카드는 poe.ninja, 희귀템은 거래소에서 옵션으로 검색
Ctrl+Alt+D	같은 조건으로 카카오 거래소 웹페이지 열기
F5	은신처로 이동
F6	정보 패널 (가격 급상승 TOP 20 등)
Ctrl+M	지도 옵션 위험도 확인
Shift+Space	설정 창
Esc	열린 창 닫기

시세 창에서는

옵션 체크와 최솟값·최댓값(마우스 휠)을 바꿔 다시 검색할 수 있습니다.
즉시 구매 / 귓속말 매물을 골라 볼 수 있습니다.
가격 분포, 7일 추세, 조작 의심 매물 표시를 함께 봅니다.
무기는 물리·원소 DPS(퀄리티 20 기준)로도 찾습니다.

그 밖에 핀, 즐겨찾기·시세 알림, 거래 알림, 맵 시간 기록, 테마(직접 만들기 포함)가 있습니다.

설치
위의 최신 버전 받기에서 설치 파일을 받아 실행합니다.
"Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행] 을 누릅니다. 코드 서명(유료 인증서)이 없는 개인 프로그램이라 뜨는 경고입니다.
관리자 권한을 묻습니다. 카카오 PoE가 관리자 권한으로 돌아가서, 오버레이도 같은 권한이어야 단축키가 게임 안에서 동작합니다.
게임은 창 모드 또는 테두리 없는 창 모드로 두세요. 전체 화면(독점) 모드에서는 오버레이가 보이지 않습니다.
새 버전이 나오면 프로그램이 알아서 받습니다.
문제가 있을 때

시세 창 아래의 [신고] 버튼을 눌러 주세요. 이유를 고르거나 직접 적을 수 있습니다.

보내는 것: 아이템 텍스트, 오버레이가 만든 검색 조건, 검색 결과 수, 버전
보내지 않는 것: 계정·캐릭터 이름, 판매자 이름, 게임 로그, 설정, PC 정보

신고는 버튼을 누를 때만 보내집니다. 모인 신고로 다음 버전을 고칩니다.

지우기

Windows 설정 → 앱에서 "PoE 시세 오버레이"를 제거합니다. 설정과 테마는 %APPDATA%\PoEPriceOverlay 에 남아 있으니, 완전히 지우려면 이 폴더도 지우세요.
