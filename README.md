# PoE 시세 오버레이 (카카오 서버)

패스 오브 엑자일 **카카오 서버**용 무료 시세 확인 도구입니다.
게임에서 아이템에 마우스를 올리고 `Ctrl+D`를 누르면, 게임 화면 위에 시세 창이 뜹니다.

### [⬇ 최신 버전 받기](https://github.com/Sulhwa99/poe-price-overlay-releases/releases/latest)
`PoEPriceOverlay-Setup-x.y.z.exe` 를 받아 실행하면 됩니다. 이후 업데이트는 자동입니다.

## 단축키

모든 단축키는 설정 창(`Shift+Space`) → **단축키** 탭에서 바꿀 수 있습니다.

| 단축키 | 기능 |
| :--- | :--- |
| `Ctrl+D` | **시세 창** — 마우스 아래 아이템의 시세 |
| `Ctrl+Alt+D` | 같은 조건으로 카카오 거래소 웹페이지 바로 열기 |
| `Ctrl+M` | **지도 확인** — 지도 옵션 중 위험한 것 표시 |
| `` ` `` | **핀** — 아이템 시세를 화면 옆에 꽂아 두기 |
| `Ctrl+Shift+X` | 핀 모두 지우기 |
| `Alt+E` | **화폐 검색 창** — 화폐 시세 검색·즐겨찾기 |
| `Ctrl+Shift+F` | 화폐 시세 급변 창 |

| `F5` | 은신처로 이동 |
| `F6` | **정보 패널** (급상승·젬 차익·세트·오늘 기록 등) |

| `Shift+Space` | 설정 창 |
| `Esc` | 열린 창 닫기 |

## 시세 창 (`Ctrl+D`)

- **어디서 가격을 가져오나**
  - 화폐·점술 카드·지도·조각 등: [poe.ninja](https://poe.ninja)
  - 고유·젬·희귀 아이템: 카카오 공식 거래소에서 그 아이템 옵션으로 직접 검색
- **옵션 골라서 다시 검색**
  - 옵션마다 체크로 켜고 끄고, 최솟값·최댓값은 마우스 휠로 조절합니다.
  - 기본으로는 값비싼 옵션 위주로 몇 개만 체크됩니다.
  - 베이스·희귀도·타락·홈(연결)·퀄리티 조건도 따로 켜고 끕니다.
- **즉시 구매 / 귓속말** 매물 중 골라서 보기 (즉시 구매가 없으면 "귓속말 매물까지 찾기" 버튼)
- 추천 가격과 디바인 환산, **가격 분포**, **7일 추세** 그래프
- 매물 목록: 같은 판매자 묶기, 터무니없이 싼 **조작 의심 매물** 표시, 내 매물 표시
- **무기**: 물리·원소 DPS(퀄리티 20 기준) 계산, DPS 조건만으로 검색
- **방어구**: 방어도·회피·보호막을 퀄리티 20 기준으로 계산해 검색
- **고유**: 옵션 굴림 범위를 막대로 표시, 같은 이름의 변형 고유 구분
- **군 주얼·지도**: 소형 패시브 효과, 지도 등급·특수 지도(악몽·수호자 등) 자동 처리
- 분열·결합·영향(쉐이퍼·엘더 등)·삿된 옵션을 따로 표시
- 같은 조건은 10분 동안 저장된 결과를 보여 줘서 거래소를 다시 부르지 않습니다.
- ☆ 버튼으로 **즐겨찾기**, 원하는 가격이 되면 **시세 알림**
- [라이브 검색] 버튼으로 거래소 라이브 검색 페이지 열기

## 그 밖의 기능

- **지도 확인 (`Ctrl+M`)**
  - 지도 옵션 중 "진행 불가 ⛔ / 주의 ⚠"를 색으로 표시합니다. 기준은 설정에서 내 빌드에 맞게 고릅니다.
  - 상점 검색용 정규식도 만들어 줍니다.
- **맵 타이머**
  - 맵에 들어가면 시작하고 나오면 멈춥니다.
  - 사망 수, 남은 포탈, 오늘 돈 맵 수, 같은 맵 평균 시간을 보여 줍니다.
  - 게임 로그(Client.txt)를 읽기만 합니다.
- **핀 (`` ` ``)**: 여러 아이템의 시세를 화면 옆에 쌓아 두고 비교합니다. 등급(쓸만함 판정) 표시도 함께 나옵니다.
- **정보 패널 (`F6`)**
  - 급상승: 가격이 오른 것·내린 것 TOP 20
  - 젬 차익: 레벨·퀄리티 올려 팔 때 남는 젬
  - 세트: 세트 판매용 수량
  - 오늘 기록: 맵 시간·사망·거래 상대
  - 오늘 조회: 오늘 찾아본 아이템
  - 리그: 남은 기간
- **거래 알림**: 누가 귓속말로 사겠다고 하면 알림 카드를 띄우고, 창고에서 그 칸을 강조합니다.
- **빠른 채팅 (`Ctrl+Shift+Q`)**: 자주 쓰는 채팅을 버튼으로 만들어 둡니다. 버튼 한 번에 한 줄만 보냅니다.
- **Ctrl + 휠 창고 탭 이동 (선택 기능 · 기본 꺼짐)**
  - 설정 → 단축키 → 편의 기능에서 켭니다. 게임이 활성화된 동안 `Ctrl` + 마우스 휠 한 칸마다 게임에 좌/우 화살표 키를 **한 번** 보내 창고 탭을 넘깁니다 (방향 반전 옵션 있음).
  - 연속 입력이나 자동 반복은 없습니다. `Ctrl` + 휠을 아이템 옮기기에 쓰는 분은 탭이 넘어갈 수 있으니 필요할 때만 켜세요.
  - **Grinding Gear Games가 이 기능을 공식 허용한다고 확인한 것은 아닙니다. 켜서 생기는 모든 문제의 책임은 사용자에게 있습니다.** 처음 켤 때 같은 안내가 나오며 동의해야 켜집니다.
- **테마**
  - 기본 테마 여러 개(어두운 테마·밝은 테마)를 고를 수 있습니다.
  - 테마 파일을 직접 만들어 넣을 수 있습니다(색, 장식, 창 밖으로 걸치는 귀·배지 등).
  - 앱 아이콘 색도 테마를 따라갑니다.
- **화면 설정**: 글꼴(기본 Pretendard · 나눔스퀘어 · 메이플스토리), 글자 크기, 창 투명도를 바꿀 수 있습니다. 설정하는 동안 게임 위에 미리보기가 뜹니다.
- **리그 자동 선택**: 현재 리그를 자동으로 골라 시세를 가져옵니다.

## 설치

1. 위의 **최신 버전 받기**에서 설치 파일을 받아 실행합니다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 **[추가 정보] → [실행]** 을 누릅니다.
   코드 서명(유료 인증서)이 없는 개인 프로그램이라 뜨는 경고입니다.
3. 관리자 권한을 묻습니다. 카카오 PoE가 관리자 권한으로 돌아가서, 오버레이도 같은 권한이어야 단축키가 게임 안에서 동작합니다.
4. 게임은 **창 모드** 또는 **테두리 없는 창 모드**로 두세요. 전체 화면(독점) 모드에서는 오버레이가 보이지 않습니다.
5. 트레이(작업 표시줄 오른쪽 아래)에 아이콘이 뜨면 준비 완료입니다. 게임에서 `Ctrl+D`를 눌러 보세요.

## 문제가 있을 때

시세 창 아래의 **[신고]** 버튼을 눌러 주세요. 이유를 고르거나 직접 적을 수 있습니다.

- 보내는 것: 아이템 텍스트, 오버레이가 만든 검색 조건, 검색 결과 수, 버전
- 보내지 않는 것: 계정·캐릭터 이름, 판매자 이름, 게임 로그, 설정, PC 정보

신고는 버튼을 누를 때만 보내집니다. 모인 신고로 다음 버전을 고칩니다.

## 지우기

Windows **설정 → 앱**에서 "PoE 시세 오버레이"를 제거합니다.
설정·테마·기록은 `%APPDATA%\PoEPriceOverlay` 와 `%APPDATA%\PoE 시세 오버레이` 에 남아 있으니, 완전히 지우려면 이 두 폴더도 지우세요.
